# hangoeun16.github.io

Personal site of Summer (Goeun) Han. Plain Jekyll, no theme.

- `index.md` about · `work.html` · `blog.html` (writing) · `library.html` · `cv.html` · `contact.html`
- CV and work entries live in `_data/cv.yml` and `_data/work.yml`
- Contact links and the résumé path live in `_config.yml`
- Posts go in `_posts/`. Add `hidden: true` to keep a post off the writing list.
- Optional post front matter: `note` (small text under the date on the left), `thumb` (small square image), `colophon` (line before the publish date)

Local preview: `bundle install && bundle exec jekyll serve`
